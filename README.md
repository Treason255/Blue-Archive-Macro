# Blue Archive Macro
### A macro for automating dailies in Blue Archive
<br>

**requires <a href="https://www.autohotkey.com">AutoHotkey v2.0</a>**

## Info
I made this macro as a level 90 who is too lazy to do their dailies. This macro is not meant to "cheat" the game by getting any kind of advantage over other players, it is simply meant to automate typical daily tasks for rewards that pretty much all gacha games have.

To run use the macro, simply launch the .ahk file.
